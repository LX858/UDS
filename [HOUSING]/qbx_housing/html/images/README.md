# Hướng dẫn thêm hình ảnh cho houses

Thư mục này chứa hình ảnh hiển thị trong NUI cho các loại nhà.

## Tên file hình ảnh:

Đặt hình ảnh với tên tương ứng loại nhà:

- `slum.jpg` - Hình ảnh cho nhà ổ chuột
- `regular.jpg` - Hình ảnh cho nhà thường
- `apartment.jpg` - Hình ảnh cho nhà chung cư
- `homestay.jpg` - Hình ảnh cho homestay
- `house-default.jpg` - Hình ảnh mặc định

## Kích thước khuyến nghị:

- Độ phân giải: 1280x720 hoặc tương tự (16:9)
- Format: JPG hoặc PNG
- Dung lượng: Nên dưới 500KB để tải nhanh

## Lưu ý:

1. Đảm bảo hình ảnh có chất lượng tốt
2. Nên chọn ảnh có độ sáng vừa phải
3. Tránh ảnh quá tối hoặc quá sáng
4. Có thể sử dụng ảnh từ GTA V hoặc ảnh minh họa

## Nếu không có hình ảnh:

Resource sẽ sử dụng `house-default.jpg` làm ảnh mặc định.
Bạn có thể tạm thời tạo file placeholder hoặc sao chép cùng một ảnh cho tất cả.
