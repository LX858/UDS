# Installation — xn_prop_com

1. Copier le dossier `xn_prop_com` dans `resources/` de votre serveur FiveM.
2. Ajouter `ensure xn_prop_com` dans server.cfg.
3. Redémarrer le serveur.
4. Spawner le prop :
   - par script : `CreateObject(GetHashKey('xn_prop_com'), x, y, z, true, true, false)`
   - ou via un menu d'objets (vMenu → Object Spawner), ou en mapping
     (CodeWalker / Menyoo) avec le nom `xn_prop_com`.
