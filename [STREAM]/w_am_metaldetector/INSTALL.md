# Installation — w_am_metaldetector

1. Copier le dossier `w_am_metaldetector` dans `resources/` de votre serveur FiveM.
2. Ajouter `ensure w_am_metaldetector` dans server.cfg.
3. Redémarrer le serveur.
4. Spawner le prop :
   - par script : `CreateObject(GetHashKey('w_am_metaldetector'), x, y, z, true, true, false)`
   - ou via un menu d'objets (vMenu → Object Spawner), ou en mapping
     (CodeWalker / Menyoo) avec le nom `w_am_metaldetector`.
