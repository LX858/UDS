Put your own images here and reference them as
  nui://oxlyn-notifykit/web/img/<file>
(then `restart oxlyn-notifykit`). Examples:
  · a notification icon / avatar / image:  icon = 'nui://oxlyn-notifykit/web/img/logo.png'
Any .png / .jpg / .webp / .gif / .svg in this folder is served to the NUI (fxmanifest files{}).
